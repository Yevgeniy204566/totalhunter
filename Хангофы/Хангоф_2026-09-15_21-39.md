### 2. Новое: периодический сброс списка склепов в начало
Владелец описал живой игровой приём: двойной клик по «Арена» → список склепов возвращается в
начало. Раньше использовался только когда бот доходил до конца списка. Запрошено сделать это
**отдельной, независимой периодической функцией**.

**Аудит перед реализацией** (по прямому требованию владельца — сначала найти, что уже есть):
1. Конец списка определяется в `_scroll_and_find()` — сравнение кропа `MENU_SCAN_REGION` до/после
   скролла.
2. Переход в «Арену» — координата `WT_ARENA_TAB`, офсет `"arena_reset"`, доступна сразу после
   `_open_watchtower()`.
3. Двойной клик уже реализован в `_reset_search()` — переиспользован БЕЗ дублирования.
4. Настройки коллектора — `profiles/profile_*.json` / `gui_config.json`, читаются/пишутся в
   `main.py` (`_save_crypt_settings`, `_load_crypt_from_profile`, `_load_crypt_settings`).
5. Существующий периодический таймер (авто-стоп) реализован **целиком на стороне GUI**
   (`self.after(1000, self._crypt_tick_timer)`) — он только останавливает бота, не кликает в игре.
   Для клика внутри уже идущего цикла бота это не годится (гонка потоков) — единственная безопасная
   модель — таймер внутри самого потока движка.

**Реализация**: `start(periodic_reset_sec=...)`, поля `_periodic_reset_sec`/
`_next_periodic_reset_at` (`time.monotonic()`, как и другие дедлайны в файле). Проверка — **в самом
начале `_run_cycle()`, сразу после `_open_watchtower()`, до начала поиска** — точка, которую
явно указал владелец («открыл меню → сначала сброс → потом поиск как обычно»). Сам цикл сбора
(поиск → отправка капитана → ожидание марша) не тронут ни строкой — сброс физически не может
произойти посреди марша. Перепланирование таймера централизовано **внутри `_reset_search()`** —
неважно, что вызвало сброс (конец списка / pre_skip / периодика), следующий периодический сброс
всегда откладывается на полный интервал вперёд.

UI: dropdown рядом с авто-стопом, значения 10/20/30/60 мин / Выкл.

  выбран одиночный значок **`↻`** (семантически точнее «перезапуск/цикл», чем абстрактная
  стрелка вверх). Убраны все 19 переводов текстовой подписи как более ненужные (mechanical bulk
  removal через Python regex, проверено что осталось ровно 0 вхождений).
- Новые дефолты по прямой просьбе владельца: Сброс — 10 мин, Стоп (штуки) — 100, Стоп (часы) — 3 ч.
  (было «Выкл» у всех трёх).
- Живой счётчик **«Собрано склепов: N»** над кнопкой Старт (зелёный `#4ADE80`, жирный) — отдельно

  использует существующий `self._crypt_found_count` (без дублирования состояния).
