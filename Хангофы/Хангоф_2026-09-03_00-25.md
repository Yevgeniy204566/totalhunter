## Технические уроки (закреплены в ANTI-PATTERNS.md)

- `Environment=` append в systemd override.conf без ведущего перевода строки может
  склеить значения — добавлять `\n` ПЕРЕД новой строкой, не только после.
- Fail-closed на отсутствующее поле стороннего API — проверять на живых данных перед
  боевым включением, не полагаться на образец из прошлой сессии.
- (Новый, не в ANTI-PATTERNS, но важно для следующей сессии по BlackSea): UI редактора
  BlackSea регулярно НЕ коммитит поле, если кликнуть «Зберегти» сразу после ввода —
  проверять актуальное значение через `document.querySelector(...).value` напрямую
  перед сохранением, `find`-инструмент про state тоглов иногда врёт.
- Классификатор безопасности Claude Code блокирует прямой доступ к прод-БД и секреты
  в командах независимо от разрешений пользователя в чате — не пытаться обходить,
  просить владельца выполнить самому (Cloud Shell — рабочий канал).
