### 3. Калибровка (Track C) — новая, ПОЛНЫЙ ЦИКЛ Stage 1–9, Final Gate (файлы 32–37)

Ключевое архитектурное решение Design: единый реестр данных с полями `kind`/`storage`/`theme`, заменяющий
`TUNE_TARGET_NAMES`/`_TUNE_POINT_TARGETS`/`_CHEST_TUNE_RECTS`. Рекомендуемые значения для всех 19
`CTkSlider` бота — реальные значения считаны из работающего бота владельца
(`Downloads\TotalHunter\_internal\profiles\profile_client.json` + `gui_config.json`), с одним явным
owner override (дальность марша Картера — 120 сек вместо фактических 202). Форма — зелёная зона на шкале
(±5% диапазона, провизорно), без кнопки возврата.

поведение (проверено лично — `crypt_hunter.py`/`navigator.py` читают `coord_manager` напрямую); resize
зелёной зоны требует реального теста, не только чтения кода; `base_pos_fn` не должна кэшироваться как
число. 13 тестов (T-01…T-13). **Final Gate пройден без открытых архитектурных вопросов** — только явно
переданные в PLAN пункты (реальный URL видео, контейнерная иерархия виджетов, провизорная ширина зоны).
