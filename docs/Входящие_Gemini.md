**Концепция: Асинхронный сканер с фоновым OCR координат миникарты**

**Суть архитектуры:** Разделение процесса навигации и процесса распознавания на два независимых потока (Producer-Consumer), обменивающихся полными снимками экрана через буферную очередь.

**Этап 1: Быстрое картографирование (Producer)**

* Движок навигации делает шаг по карте с максимально возможной скоростью, игнорируя стандартные задержки.
* Сразу после сдвига делается снимок всего экрана (`sct.monitors[1]`). Кропы не используются согласно Золотому Правилу YOLO.


* Полученный кадр (`frame`) помещается в потокобезопасную очередь (`queue.Queue`).
* Навигатор не ждет ответа от нейросети и немедленно переходит к следующему сдвигу.

**Этап 2: Фоновый анализ (Consumer)**

* Отдельный поток-обработчик (daemon) непрерывно извлекает кадры из очереди.
* Нейросеть (YOLO) анализирует кадр на наличие биржи со своей собственной скоростью.

**Этап 3: Локализация через OCR миникарты**

* Если YOLO обнаруживает биржу на конкретном `frame`, система не пытается взаимодействовать с самой игрой, так как реальная карта уже сдвинулась.
* Алгоритм обращается к *этому же* статичному кадру, на котором была детекция.
* Из кадра выделется левый ижний угол и от туда распохзнаются коодрдианты квадрата -на которм распозналась биржа.



**Этап 4: Уведомление и выдача результата**

* Бот издает звуковой сигнал.
* Система сохраняет целевой скриншот с найденной биржей на диск.
* В лог или пользовательский интерфейс выводится алерт с прочитанными координатами: `Биржа найдена. Квадрат: X: ... Y: ...`.
* Собранный скриншот предоставляется для дальнейшего распознавания или ручной обработки.

**Готово:** формализованный технический дизайн конвейера фонового распознавания скринов без искусственных задержек.

**Архитектура: Асинхронный конвейер (Producer-Consumer)**
Для реализации отвязки скорости сбора от скорости распознавания логика делится на два независимых потока, которые общаются через потокобезопасную очередь.

**1. Буфер кадров (Очередь)**

* Инициализируется объект `queue.Queue(maxsize=50)`.
* Выступает в роли буфера-накопителя, позволяя движку накидывать скрины со своей скоростью, пока нейросеть разбирает их со своей.

**2. Поток-генератор (Навигатор)**

* Отвечает исключительно за захват и навигацию.
* Делает снимок полного экрана без кропов (`sct.monitors[1]`).
* Сразу помещает полученный кадр в очередь: `queue.put(frame)`.
* Двигает карту дальше с требуемой максимальной скоростью, не дожидаясь ответа от нейросети.

**3. Поток-обработчик (Фоновый YOLO)**

* Отдельный `daemon`-поток, непрерывно работающий в фоне.
* Достает очередной кадр из очереди: `frame = queue.get()`.
* Выполняет инференс на этом сохраненном кадре.
* Если на кадре обнаружена биржа, поток просто сохраняет этот конкретный `frame` на диск в выделенную папку (например, `cv2.imwrite`) и издает звуковой сигнал.

**Концептуальная схема реализации:**

```python
import threading
import queue
import cv2
import numpy as np

class FastScanner:
    def __init__(self, yolo_model):
        self.frame_queue = queue.Queue(maxsize=50)
        self.yolo_model = yolo_model
        
        # Запуск фоновой нейросети
        self.yolo_thread = threading.Thread(target=self._yolo_worker, daemon=True)
        self.yolo_thread.start()

    def _yolo_worker(self):
        save_counter = 0
        while True:
            # Чтение кадра из очереди (поток засыпает, если очередь пуста)
            frame = self.frame_queue.get()
            
            # Обработка со скоростью нейросети
            results = self.yolo_model.predict(frame, imgsz=1280, verbose=False)
            
            # Проверка детекции (логика поиска нужного класса)
            if self._has_exchange(results):
                # Выдача скрина: сохранение кадра с биржей
                filename = f"saved_exchanges/exchange_screen_{save_counter}.jpg"
                cv2.imwrite(filename, frame)
                save_counter += 1
                
                # Место для звукового алерта
                
            self.frame_queue.task_done()

    def run_fast_mapping(self, sct, navigator):
        while True:
            # 1. Быстрый скриншот полного экрана
            screen = np.array(sct.grab(sct.monitors[1]))
            frame = cv2.cvtColor(screen, cv2.COLOR_BGRA2BGR)
            
            # 2. Набивка очереди
            if not self.frame_queue.full():
                self.frame_queue.put(frame)
                
            # 3. Быстрый сдвиг карты
            navigator.step()

```

В этой реализации бот работает как пылесос: генератор набивает очередь снимками, двигая карту максимально быстро, а фоновый поток YOLO монотонно разгребает `frame_queue`, выкидывая пустые кадры и сохраняя скриншоты с биржами для их дальнейшего анализа.
