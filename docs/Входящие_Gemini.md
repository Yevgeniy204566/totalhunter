# Управление словарями и Паттерны (T5-T9) через Google Sheets

## 1. Архитектура "Админской Таблицы" (Google Sheets)

Мы создаем отдельный Google Sheet (или новые листы в существующем), который будет выступать «пультом управления». В нем будет 3 листа:

1. **Player Aliases:** Колонки `Raw Name` | `Canonical Name`. (Для исправления ников, например: `Machet` -> `MACHETE`).
2. **Chest Aliases:** Колонки `Raw Name` | `Canonical Name`. (Для исправления сундуков, например: `Эпический отр` -> `Epic Squad Chest`).
3. **Chest Catalog (Глобальный):** Колонки `Canonical Name` | `Points`. (Эталонный список из 140+ сундуков. У паттерных сундуков тут будут цифры очков, у остальных — 0).

## 2. Скрипт синхронизации (Pull from Sheets to DB)

Нам нужен новый интерим-скрипт (например, `sync_admin_sheet_to_db.py`).

* Владелец заполняет маппинг в Гугл Таблице руками.
* Затем владелец локально запускает этот скрипт.
* Скрипт читает данные из трех листов через Google Sheets API и отправляет их на сервер через новый закрытый POST-эндпоинт (с авторизацией, так как это админское действие).

## 3. Изменения на Backend (`server/chests.py` и БД)

1. **Новый эндпоинт для импорта словарей:** Принимает JSON от скрипта синхронизации и делает массовый `UPSERT` в таблицы `player_aliases` и `chest_type_aliases` (для конкретного коллектора), а также обновляет глобальную таблицу `chest_type_catalog`.
2. **Пересчет "На лету" в `GET /summary/{slug}`:**
* Существующий эндпоинт сводки должен начать применять алиасы. При `GROUP BY` сервер должен сначала проверять, есть ли `raw_name` в словаре. Если есть — группировать по `canonical_name`, если нет — оставлять как есть.
* Эндпоинт должен джоинить таблицу `chest_type_catalog`, чтобы умножить количество каждого канонического сундука на его `Points`.
* **Добавление Паттернов:** После подсчета `Total Points` для каждого игрока, бэкенд должен присвоить ему `Pattern` (Т5, Т6, Т7, Т8, Т9) на основе жестко заданных порогов (пороги пока можно вынести в константы или переменные окружения сервера на бэкенде, чтобы мы могли их тюнить).
