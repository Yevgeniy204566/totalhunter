## 5. Среднее значение по каждому типу сундука

На публичной таблице над строкой заголовков колонок добавить **строку средних значений**.

Для каждого типа сундука:

**Среднее = сумма всех значений этого столбца / количество участников, актуальное на момент добавления последних данных.**

То есть это **среднее по участникам**, а не среднее арифметическое отдельных поступлений.

### Важно

* Использовать количество участников, фактически присутствующих в таблице на текущий момент.
* При добавлении новых данных пересчитывать среднее.
* Если участник имеет `0` сундуков — его `0` входит в расчёт.
* Не учитывать саму строку среднего при расчёте.
* Средняя строка должна находиться **выше заголовков колонок**.
* Формат значения: разумное количество знаков после запятой (например `1.4`).
* Сортировка столбцов не должна влиять на расчёт среднего.
* При изменении количества участников средние должны автоматически пересчитываться.

### Пример

10 участников, над  столбцом «Эпический» суммарно 37 сундуков:

**37 / 10 = 3.7**

В верхней строке колонки «Эпический» показывается **3.7**.
