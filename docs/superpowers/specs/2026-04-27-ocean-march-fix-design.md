# Ocean March Fix — Design Spec
**Date:** 2026-04-27  
**File:** `navigator.py` — `CoastalSnakeNavigator.step()`  
**Status:** Approved

---

## Problem

Бот уходит в океан на изрезанном рельефе (острова, полуострова).  
При переходе HOMING→DIVING не проверяется направление нырка.  
Если впереди чистый океан — бот всё равно ныряет.

---

## Root Cause

В блоке `if info['is_at_coast']:` переход в DIVING происходит безусловно.  
`fwd['land_px']` вычисляется в `_read_minimap()` но не используется как стоп-сигнал.

---

## Physical Constraint

Миникарта показывает не более **3 экранов** от центра джойстика в любую сторону.  
Если в зоне видимости (3 экрана) нет суши — это реальный океан, нырок запрещён.  
Если суша есть хотя бы в одном пикселе — нырок разрешён (могут быть каналы на пути).

---

## Design

### Изменяется: только переход HOMING→DIVING

**Место:** `navigator.py`, метод `step()`, блок `if info['is_at_coast']:`

**Добавляем 4 строки перед переходом в DIVING:**

```python
fwd = info['fwd']
if fwd['land_px'] == 0 and fwd['water_px'] > self.min_water_px:
    self._shift_click()   # чистый океан → пропустить колонку
    return True           # остаёмся в HOMING
# иначе — суша есть → нырок как обычно
```

### Не изменяется

| Компонент | Статус |
|-----------|--------|
| HOMING (движение к берегу) | без изменений |
| DIVING (счёт шагов) | без изменений |
| RETURNING (возврат к берегу) | без изменений |
| `_inland_vec` — динамический, пересчёт при каждом HOMING→DIVING | без изменений |
| `analyze_forward_zone` вызов с `radius=60` | без изменений |

### Принципы (не нарушать)

1. `land_px == 0` → чистый океан → сдвиг, без физического входа в воду
2. `land_px > 0` → суша есть (остров, берег, хотя бы 1px) → нырять
3. `dive_vec` остаётся **динамическим** — не фиксировать
4. Не добавлять аборт в DIVING при `is_water` — сломает исследование каналов
5. Симметрия движения: правило одинаково для прямого и обратного хода (но сейчас реализуется только для forward)

---

## Scope

Минимальное изменение — 4 строки в одном месте.  
Всё остальное нетронуто.
