## Что это за замысел в одном абзаце

Биржа 2.0 — recon-сканер: змейка (`CoastalSnakeNavigator`) проходит королевство без ожидания нейросети и складывает кадры на диск,
фоновый consumer прогоняет их через YOLO; найденную биржу фиксирует в журнале, списывает 10◆, читает координаты OCR с сохранённого
кадра и публикует находку на сайте в разделе «Рой» (Telegram не используется). Интерфейс показывает очередь необработанных кадров,
паузит змейку при переполнении, различает состояния «обход идёт / анализ очереди / всё обработано». Отдельной задачей во входящих
стоит рефакторинг калибровки и рекомендуемых значений ползунков.

## Решения владельца, уже принятые и действующие для всего концепта

1. Публикация находок — на сайте в разделе «Рой»; Telegram для 2.0 не используется.
2. Списание 10◆ с отдельным `hunt_type`; лимит «не чаще 1 раза в 2 с» снят только для 2.0; Биржа 1.0 не изменяется.
3. Дедупликации находок сейчас нет и не вводится (входящие просят «проверить» — решение владельца: не нужно).
4. Очередь не ограничена, кадры не выбрасываются; пауза змейки на пороге — механизм балансировки, а не лимит очереди.
5. Глубина нырка до 50 — то же поведение цикла с другим числом итераций, не отдельный риск.
6. X/Y с кадра — приблизительная позиция экрана, а не координаты биржи.
7. Агенты не используются без явного «да» владельца.
8. Калибровать нужно все 12 точек (2 якорные + 7 склепы/биржи + 3 сундуки) — 17a.
9. `ESC` работает всегда, во всех состояниях; «обход королевства» — образное выражение, такой функции нет — 17d.
10. «Пауза змейки» — образное выражение: автоматический Стоп и позже Старт; возобновление при загрузке очереди 10% — 17c.
11. **Конвейер:** кадр удаляет только consumer после обработки (в том числе найденный — после передачи координат на сайт); при Стоп, Старт и автопаузе ничего не удаляется, очередь сохраняется; скрины не копятся — 17c, 17d.
12. 100% индикатора = порог паузы (~300 кадров); возобновление при 10% (~30) — подтверждено — 17c.
13. Статусы: коричневый = змейка остановлена, очередь не пуста; зелёный = очередь пуста — подтверждено — 17d.
14. Индикатор статуса — нужен, делается в стиле бота (палитра MD3) «в пределах разумного», дизайн правится по ходу — 17d.
15. Блок «Настройки змейки» в 2.0 — те же настройки, что у обычной змейки (скорость, шаг и остальные); диапазоны скорости будут другими, потому что без нейросети змейка быстрее — 17b.
16. Видео для калибровки — только гиперссылка на YouTube, видео внутри бота не будет — 17a.
