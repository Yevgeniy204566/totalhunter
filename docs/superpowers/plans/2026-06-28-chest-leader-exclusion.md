# Chest Leader Exclusion — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a clan admin mark one player as "Глава" and exclude specific chest types from counting in their score, without affecting other players.

**Architecture:** Two new nullable columns on `ChestCollector` store the leader name and excluded catalog IDs (JSONB array). `pivot_summary()` filters rows in Python before building the pivot — no SQL changes. A new `PATCH /{slug}/leader` endpoint saves the config; the Players tab in `/dashboard/chests` gains a radio column and inline exclusion panel.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy async, Alembic, React JSX, pytest-asyncio, httpx AsyncClient

## Global Constraints

- Never modify `server/main.py` without diagnosing root cause first
- All new backend code follows existing file patterns (no new top-level files unless spec says so)
- `pivot_summary()` signature change must be backward-compatible (keyword-only args with defaults)
- Frontend state pattern: per-collector dicts keyed by `slug` (matches `rowsByCollector`, `playerRowsByCollector`, `seasonByCollector`)
- Tests: use `pytest.mark.asyncio` + `AsyncClient(transport=ASGITransport(app=app))` for integration tests; pure function tests need no fixtures

```javascript
      await api.dashboardChestsPlayerAliases(slug, playerRowsByCollector[slug])
      const profileRows = (playerRowsByCollector[slug] || [])
        .filter(r => (r.canonical_name || r.raw_name || '').trim())
        .map(r => ({
          canonical_name: r.canonical_name || r.raw_name,
          rank: r.rank || null,
          troop_level: r.troop_g && r.troop_s && r.troop_m
              ? `G${r.troop_g} S${r.troop_s} M${r.troop_m}`
              : null,
        }))
      await api.dashboardChestsPlayerProfiles(slug, profileRows)
      await api.dashboardChestsLeader(slug, {
        leader_canonical_name: leaderByCollector[slug] || null,
        leader_excluded_catalog_ids: leaderExcludedByCollector[slug] || [],
      })
      setMsg(cx.saved)
    } catch (e) { setMsg(e.message) }
  }
```
