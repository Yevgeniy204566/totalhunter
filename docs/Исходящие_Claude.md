## Хангоф #83 | 2026-06-02 | v1.6.4 — ROY OCR portable Tesseract

### Что сделано

**ROY OCR fix — корень проблемы: у клиентов без калибровки координаты не передавались в РОЙ**

Три взаимосвязанных фикса в `roy/exchange_reader.py`:

1. **Динамический ROI** (замена hardcoded coord_manager)
   - Было: `coord_manager.to_region(660, 250, 600, 200)` — зависел от калибровки профиля
   - Стало: `mss.monitors[1]` центр 60% — работает на любом разрешении без калибровки
   - Один захват экрана → верхняя половина = K:X:Y, нижняя = прогресс

2. **Автопоиск Tesseract** (замена hardcoded пути)
   - Было: `C:\Program Files\Tesseract-OCR\tesseract.exe` — падало молча на D: и x86
   - Стало: `sys.frozen` → `tesseract_bin/` рядом с exe; dev → PATH → C: → D: (x86)
   - Явная ошибка в `roy_debug.log` если не найден

3. **Portable Tesseract** (`tesseract_bin/` в сборке)
   - `build_release.py` копирует `tesseract_bin/` рядом с `TotalHunter.exe` (как README.txt)
   - `.gitignore` дополнен — 65 МБ DLL не идут в репо
   - tessdata очищена: только `eng.traineddata` (3.9 МБ), убраны 6 языков + osd + Java-файлы
   - Экономия: 98 МБ → 65 МБ

**Тест подтверждён:**

## Хангоф #82 | 2026-06-02 | v1.6.3 — клик по бирже + переводы тюнинга

### Что сделано

**Фикс клика по бирже (navigator.py)**
- Было: `pyautogui.click(cx, cy)` — мгновенный телепорт, клик через раз
- Стало: `moveTo(cx, cy, duration=0.15)` + `sleep(0.05)` + `click()`
- Причина сбоя: карта имеет инерцию; 0.5с settle иногда недостаточно; плавный подвод даёт +200мс буфера — карта гарантированно стоит к моменту клика
- Диагностика подтверждена через nav_debug.log + Входящие_Gemini.md

**Переводы D-Pad тюнинга (main.py)**
- Секция «Тюнинг кликов» в вкладке КАЛИБРОВКА переведена на все 19 языков
- Новые ключи: `cal_tune_title`, `cal_tune_wt_icon`, `cal_tune_carter`, `cal_tune_top_accel`, `cal_tune_march_accel`, `cal_tune_reset`
- Выбор хранится по индексу `self._tune_idx` (0=wt_icon, 1=carter, 2=top_accel, 3=march_accel)
- При смене языка дропдаун перестраивается, выбранный объект не сбрасывается
- Заголовок и кнопка Сброс зарегистрированы в `_i18n_labels` — обновляются автоматически
