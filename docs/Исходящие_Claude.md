### Корень проблемы

Межкарточный сепаратор между card 0→1→2 оказался **~25px**, а не ~10px как предполагалось.

**Реальное расположение внутри card_N (PITCH=86):**
```
Card 0 (нет сепаратора сверху):
  y=0..3:   тонкая верхняя рамка
  y=3..20:  имя игрока
  y=20..35: статус «В сети» / «Не в сети» (зелёный текст)

Card 1+ (есть сепаратор ~25px сверху):

  y=57..77: могущество
  y=77..86: нижняя рамка
```

**Почему OCR читает «В сети» вместо имени:**
- Наш кроп NAME_Y1=3, NAME_Y2=40 захватывает для Card 2: y=3..40
- В этой зоне есть: сепаратор (y=0..25) + начало имени (y=25..40)
- НО: статус «В сети» — зелёный высококонтрастный текст — начинается у y≈35
- Tesseract предпочитает зелёный «В сети» над светлым мелким именем
- Результат: вместо «Нилагринн» — «В сети»

### Почему Фаза 2 (tournament_reader) работала, а Фаза 0 нет

**Фаза 2 — плоская таблица**: каждая строка = одно текстовое поле (ранг|имя|очки). Нет соседних текстовых элементов, нет декора, нет статуса онлайна. 1 поле → 1 позиция → OCR прав почти всегда.

**Фаза 0 — сложная карточка**: внутри одной карточки есть:
1. Имя (светлый текст, мелкий)
2. «В сети» / «Не в сети» (ЗЕЛЁНЫЙ жирный, высококонтрастный)
3. Могущество (цифры)
4. Иконки/декор

Tesseract берёт самый контрастный текст в кропе — это всегда «В сети», не имя.

### Проблема 1: ГЛАВА — pitch не определён
- Вкладка ГЛАВА: `detect_card_pitch` вернула `None` → 0 участников считано
- Причина неизвестна: либо threshold=25 слишком высокий (мало контраста на рамках),
  либо HEADER_HEIGHT_PX=35 слишком много и реальный header меньше/больше
- Нужен: debug-скриншот панели на вкладке ГЛАВА + градиентный профиль

### Проблема 2: Ведущие артефакты в именах (`|`, `}`, `‚`, `'`)
- Примеры: `| Адорус`, `} Sarmat`, `‚ Strongholst`, `'Мисливець`
- Причина: рамка карточки слева от имени (вертикальная линия) читается как `|`
  Иконки/символы на верхнем крае карточки → `}`, `‚`
- NAME_X_FRAC=(0.14, 0.62): левая граница x=0.14×724=101px, может нужно сдвинуть на 0.17-0.18
- **Частичный фикс в _clean_name**: добавить `re.sub(r'^[|}\'\`"‚\s\[\]!i]+', '', text)`

### Проблема 3: Координаты (K:229 X:478 Y:516) не вырезаются
- Текущий regex: `re.sub(r'\s*\(.*', '', text)` — не работает когда OCR читает `(` как `|`, `{`, `i`
- Примеры: `DN prot 229 E40 Y:524`, `Wells { m229 X:484 Y:518`, `ALFAKURT i 229 X:467 Y:481`
- Нужен более широкий паттерн, например:
  ```python
  text = re.sub(r'\s*[\(\{\|\[iI]\s*[KkКкRr]:?\s*\d+.*', '', text)
  text = re.sub(r'\s+[KkКкR]:?\s*\d{1,3}[\s:].*', '', text)
  ```
- Или: обрезать по ГОРИЗОНТАЛЬНОЙ позиции — детектировать где начинается синий подчёркнутый текст

### Проблема 4: Значения могущества неправильные
- Пример: `| Адорус — 92214017437` (92B) вместо реального ~1.8B
- Из скрина Старший видно: MAXLINDER=2,013,008,746, Адорус=1,821,401,745
- Возможные причины:
  a) pitch неправильный → кроп might_roi захватывает часть соседней карточки
  b) MIGHT_X_FRAC=(0.64, 0.98) захватывает иконку уровня аватара из нижней карточки
  c) Scrollbar region на правом краю даёт лишние цифры
- Нужен: _dbg_roster_might_0.png чтобы увидеть что именно в кропе
