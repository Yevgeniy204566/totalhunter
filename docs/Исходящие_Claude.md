### Пост 1/6 — Склепы

```
Склепы — бот сам ищет склепы на карте, отправляет войска и ждёт нужного момента,
без ручного контроля за таймером.

Как это устроено:
Бот не распознаёт текст с таймером на экране — это было бы медленнее и рискованнее.
Вместо этого он использует формулу: время в пути до склепа делится пополам с каждым
повторным подходом (T_max / 2^N), пока не подгадает момент открытия. Формула не
зависит от языка игры — работает одинаково на любом клиенте.

Настройки (вкладка Склепы):
— Дальность марша (7–15 мин) — сколько по времени бот считает «доступным» для похода
— Ускорение марша (0–5) — если у вас куплено ускорение маршей в игре
— Скорость кликов (0.0 с) — пауза между действиями бота
— Swing 1/2 (Исследовать/Ускорение) — сдвиг точки клика, если бот промахивается
  мимо нужной кнопки

Запуск: выбери типы склепов -> прокрути карту на максимальный зум -> ЗАПУСТИТЬ СБОР.
```

### Пост 2/6 — Биржи

```
Биржи — бот ищет биржи на карте, двигаясь вдоль береговой линии по фиксированному
циклу движения.

Как это устроено:
Цикл движения — нырок (в воду, к точке поиска) -> сдвиг вдоль берега -> возврат
к «маяку» (фиксированной точке на суше) -> снова сдвиг. Пока бот возвращается
к маяку, это имеет наивысший приоритет — движение не прерывается раньше времени.
Поиск объектов на экране (YOLO) работает по полному разрешению экрана, без обрезки
краёв.

Настройки (вкладка Биржи):
— Скорость работы (0.5–0.9 с) — пауза между действиями бота
— Шаг (15–19 px) — размер одного сдвига джойстика на карте
— Глубина нырка (4–6) — сколько шагов бот делает в сторону воды перед возвратом

Запуск: отключи слой городов игроков -> прокрути карту на минимальный зум -> СТАРТ.
```

### Пост 3/6 — РОЙ

```
РОЙ — обмен координатами найденных бирж между участниками клана в реальном времени,
пока каждый из них запускает бота отдельно.

Как это устроено:
Когда чей-то бот находит биржу, координаты автоматически отправляются всем
подключённым к РОЮ участникам клана через сервер, со звуковым сигналом о новой
находке. Собственные находки не дублируются звуком — уведомление приходит только
о чужих. РОЙ активен в периоды игрового события «Торговые Пути».

Зачем это нужно: несколько ботов клана не тратят время на поиск одной и той же
уже найденной биржи.

Запуск: включается на той же вкладке БИРЖИ рядом с основным поиском.
```

### Пост 4/6 — Сундуки

```
Сундуки — бот читает клан-чат прямо с экрана игры и сам записывает, кто и какой
сундук сдал, без ручного заполнения таблиц.

Настройки (вкладка Сундуки):
— Королевство / Клан — номер королевства и тег клана (например: 229 / BERS)
— Источник — фильтр по отправителю сундука (пусто = собирать от всех)
— Имя игрока — собирать только от одного игрока (пусто = от всех)
— Скорость клика — пауза между кликами (реальная пауза всегда от 0.3 с — столько
  занимает распознавание текста)
— Light / Full — набор языков распознавания имён: Light = латиница+кириллица
  (быстрее), Full = все 19 языков (медленнее, для нелатинских ников)

Запуск: нажми СТАРТ, результаты сохраняются на сервер автоматически.

На сайте (личный кабинет -> Сундуки):
— Публичная страница клана — ссылка без входа в аккаунт, показывает сводную
  таблицу по игрокам и типам сундуков за текущий 2-недельный цикл события
  «Торговые Пути», плюс историю прошлых циклов
— На этой же странице игроки сами могут указать своё звание и состав войск —
  эти данные общие с модулем Древний
— Лидер клана настраивает, какие типы сундуков засчитываются в общий рейтинг,
  может исключить турнирные награды главы клана из подсчёта (это не личный
  вклад игрока) и задать псевдонимы, если распознанное имя не совпало с реальным

ТЮНИНГ (если бот кликает не туда): вкладка Калибровка -> Тюнинг -> выбери пункт ->
сдвинь позицию клика стрелками D-Pad.
```

### Пост 5/6 — Древний

```
Древний — расчёт нормы урона по игроку на событие «Древний» и учёт того, кто
сколько реально нанёс.

Как пользоваться ботом:
1. Открой в игре ростер турнира «Древний» (Старший / Древний).
2. Переключись на вкладку Древний в Total Hunter.
3. Нажми СКАНИРОВАТЬ — бот считывает все видимые строки (имя, место, очки).
4. Нажми ОТПРАВИТЬ — данные уходят на сервер.

Расчёт нормы (личный кабинет -> Древний):
Норма делится между игроками одним из двух способов на выбор:
— По званию — норма делится между Офицерами и Ветеранами, у офицера вдвое
  больше нормы, чем у ветерана
— По составу войск — норма пропорциональна тиру войск игрока (Земля/Осада/
  Конница): чем выше тир, тем больше норма

Подсветка недобора: лидер задаёт три порога недобора нормы в процентах —
строка игрока в таблице подсвечивается жёлтым/оранжевым/красным при недоборе
по этим порогам.

Публичная страница (без входа в аккаунт): каждый игрок сам вписывает своё
звание и состав войск по ссылке, которую лидер кидает в клан-чат — не нужно
опрашивать каждого лично. Эти данные общие с модулем Сундуки.

Слияние имён: если бот считал ник с игровыми значками (например, лишний VIP-
символ или необычный шрифт), лидер в кабинете один раз связывает его с
настоящим именем игрока — дальше очки и норма этого игрока считаются вместе,
под одним именем.

Работает и без Сундуков: игроков можно добавить в ростер вручную, указав имя,
звание и состав войск. Если клан уже ведёт учёт Сундуков — кнопка «Заполнить
из Сундуков» одним нажатием переносит список участников оттуда.
```

### Пост 6/6 — Аккаунт, кредиты, рефералка

```
Аккаунт — вся оплата и статистика бота в одном личном кабинете на сайте,
без подписки: списание кредитов только за реально выполненные действия бота.

Пополнение: оплата через NOWPayments (криптовалюта), несколько пакетов кредитов
на выбор. Зачисление автоматическое после подтверждения платежа.

Бесплатные кредиты: на вкладке «Заработать» можно посмотреть короткий рекламный
ролик и получить кредиты без оплаты.

Реферальная программа: за пользователей, пришедших по вашей ссылке, начисляется
процент от их трат — трёхуровневая система:
— Уровень 1 (прямой реферал) — 10%
— Уровень 2 — 5%
— Уровень 3 — 1%
Структуру рефералов видно в личном кабинете (дерево с зумом и перетаскиванием).
```
