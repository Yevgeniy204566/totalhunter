### 2. Критический баг биржи — найден и исправлен (v1.4.3)

**Симптом:** Бот видел биржу, отправлял фото в Telegram, но не останавливался и не играл звук.

**Причина:** В `navigator.py → _exchange_detected()` добавленный в v1.4.2 «свежий YOLO»:
```
нашли → фото в Telegram → sleep(0.15) → свежий YOLO
  если fresh_box is None → return   ← ВЫХОД ДО клика/звука/стопа/OCR
```
За 0.15с карта успевала сдвинуться → свежий YOLO промахивался → `return` → бот уходил без остановки.

**Побочный эффект:** ROY OCR (`exchange_reader.py`) никогда не вызывался с v1.4.2. Координаты K/X/Y не уходили в РОЙ-пул.

**Фикс (коммит 2ad4104):**
```python
# было:
if fresh_box is None:
    return
# стало:
if fresh_box is None:
    fresh_box = box  # fallback — биржа только что была видна
```

### 3. Пауза 0.15с → 0.5с (коммит 30245c0)
Карта успевает полностью остановиться перед свежим YOLO-сканом.
