# Total Hunter — Быстрый старт

### Шаг 1. Установка
1. Скачай архив `TotalHunter.zip` с сайта **total-hunter.com**
2. Распакуй в любую папку (например `C:\TotalHunter\`)
3. Запусти `TotalHunter.exe`
4. Войди через Google-аккаунт

---

### Шаг 2. Калибровка (обязательно, один раз)
Открой игру так, как будешь играть (браузер или клиент).

**Точка A — центр мини-карты:**
- Уменьши мини-карту до минимума
- В боте нажми **«Откалибровать A»** → кликни точно в центр мини-карты

**Точка B — Зона ресурсов — Серебро:**
- Найди иконку Серебра, наведи курсор до появления «+»
- В боте нажми **«Откалибровать B»** → кликни точно по символу «+»

**Сохрани профиль** (Клиент / Браузер 1 / Браузер 2)

---

### Шаг 3. Настройка склепов
Вкладка **СКЛЕПЫ**:

| Ползунок | Что делает | С чего начать |
|---|---|---|
| **Дальность марша** | Макс. время марша Картера | 15–20 мин |
| **Ускорение марша** | Кол-во кликов «Ускорить» | 2–3 |
| **Скорость кликов** | Пауза между кликами бота | 0.0 с |
| Swing 1 — Исследовать | Точность клика по кнопке «Исследовать» | 0 |
| Swing 2 — Ускорение | Точность клика по кнопке «Использовать» | 0 |

**Настройка Swing:** запусти бота → смотри попадает ли клик в кнопку. Если нет — жми «+» или «−» по 5px пока не попадёт.

---

### Шаг 4. Настройка бирж
Вкладка **БИРЖИ**:

| Ползунок | Что делает | С чего начать |
|---|---|---|
| **Скорость работы** | Пауза после каждого шага | 1.5–2.0 с |
| **Шаг** | Размер шага джойстика | 13–15 px |
| **Глубина нырка** | Экранов вглубь суши | 4–5 |
| Живость хода | Резкость следования за берегом | 100% |

---

### Шаг 5. Запуск

**Склепы:**
- Выбери типы склепов (Обычные / Редкие / Эпические)
- Убедись что карта прокручена на максимум
- Нажми **ЗАПУСТИТЬ СБОР СКЛЕПОВ**

**Биржи:**
- Отключи слой городов игроков на карте
- Прокрути карту на минимум (широкий вид)
- Нажми **СТАРТ**
- При находке биржи бот издаст звуковой сигнал

---

### Частые вопросы

**Бот кликает мимо кнопки «Исследовать»?**
→ Настрой Swing 1 кнопками «+» / «−»

**Бот не находит биржи?**
→ Убедись что отключён слой городов. Уменьши «Точность поиска» до 0.65

**Бот работает медленно?**
→ Уменьши «Скорость работы» до 1.0–1.5 с

**Не хватает кредитов?**
→ Купи пакет на total-hunter.com или заработай через Колесо Фортуны (+5 кр/день)
