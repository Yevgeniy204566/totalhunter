 # Total Hunter — Быстрый старт

  ### 1. Установка
  1. Скачай TotalHunter.zip с total-hunter.com
  2. Распакуй в любую папку
  3. Запусти TotalHunter.exe
  4. Войди через Google-аккаунт

  ---
  ### 2. Калибровка (один раз)
  Открой игру так, как будешь играть (браузер или клиент).

  Точка A — Центр мини-карты:
  Уменьши зум мини-карты до минимума. Кликни точно по центру прямоугольника мини-карты.

  Точка B — Зона ресурсов — Серебро:
  Найди иконку Серебра, наведи курсор до появления «+». Кликни точно по символу «+».

  Сохрани профиль: Клиент / Браузер 1 / Браузер 2

  ---
  ### 3. Склепы

  Дальность марша — 7-15 мин
  Ускорение марша — 0-5
  Скорость кликов — 0.0 с
  Swing 1 — Исследовать — 0 (настроить если мажет)
  Swing 2 — Ускорение — 0 (настроить если мажет)

  Выбери типы склепов → прокрути карту на максимум → ЗАПУСТИТЬ СБОР СКЛЕПОВ

  ---
  ### 4. Биржи

  Скорость работы — 0.5-0.9 с
  Шаг — 15-19 px
  Глубина нырка — 4-6

  Отключи слой городов → прокрути карту на минимум → СТАРТ

  ---
  ### Частые вопросы

  Бот мажет по Исследовать? → Swing 1 кнопками + / -
  Не находит биржи, а находит другое? → точность поиска 0.8
  Нет кредитов? → total-hunter.com или Колесо Фортуны
